# Evidence Pipeline

## Objective

Convert normalized discovery results into a reviewable, integrity-preserving evidence pack suitable for technical assessment and chain-of-custody discussion.

## Orchestrator

`EvidenceOrchestrator` (`src/recon/evidence/orchestrator.py`) executes writers in a fixed order and returns metadata describing generated paths.

## Artifact Catalog

| Writer | Artifact | Format |
|--------|----------|--------|
| `NormalizedWriter` | `normalized.json` | JSON |
| `ScopeRegisterWriter` | `scope-register.csv` | CSV |
| `RequestLedgerWriter` | `request-ledger.csv` | CSV |
| `EvidenceIndexWriter` | `evidence-index.csv` | CSV |
| `AssessmentManifestWriter` | `assessment-manifest.json` | JSON |
| `ContinuityWriter` | `continuity-record.md` | Markdown |
| `IntegrityWriter` | `integrity-attestation.md` | Markdown |
| `FootholdEvidenceWriter` | `foothold-evidence.txt` | Text |
| `ManifestWriter` | `manifest.sha256` | Hash list |

Optional intermediate stage dumps:

| Writer | Artifact | Format |
|--------|----------|--------|
| `RawOutputWriter` | `raw-output/*.json` | JSON |

## Integrity Model

1. Content writers emit artifacts into the configured output directory (default `output/`).
2. `ManifestWriter` runs **last** and records SHA-256 digests of the evidence set.
3. Operators (or reviewers) recompute hashes and compare against `manifest.sha256`.

Modifying any hashed file after generation invalidates the manifest until it is regenerated by a fresh evidence pass.

## Continuity and Attestation

- **Continuity record** — Narrative of assessment continuity suitable for handoff between operators/reviewers.
- **Integrity attestation** — Human-readable statement accompanying machine hashes.
- **Foothold evidence** — Captures authenticated resource proof when discovery succeeds.

## Templates

Starter templates live under `resources/templates/` (for example, assessment manifest template and evidence index template). Runtime writers own the authoritative on-disk format for a given engine version.
